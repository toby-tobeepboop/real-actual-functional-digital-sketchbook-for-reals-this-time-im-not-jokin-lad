my reflections

Adding borders and backgrounds was very helpful with visually showing where all the boxes were on the page, and how far or near they'd extend depending on the selected element. Being able to see each element's box was helpful- and knowing I can make them overlap is going to be fun for the future. I learnt I adore the way inline displays behave, and that having everything next to each other visually feels right to me. I learnt that block display is only useful for a specific kind of code in my visual style, and that I don't think I'll use it as much. Changing the display properties of the two practice texts was very fun- watching them switch properties on the live site was very cool! This is the least confused and angry I've felt while doing a practice page, and I hope they all stay this less confusing way, because the first few css basics practices were the bane of my existance.
